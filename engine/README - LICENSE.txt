
Most of the Trellis code is under MIT license, allowing for a full-commercial use.


HOWEVER, Trellis uses some nvidia code that disallows commercial use, and only allow for research / evaluation purposes.
This code prevents you from selling assets generated via Trellis right now.


	So, if you want to sell generated assets:

	- download Hunyuan 2.0 / 2.1 as well, then use it to make commercial assets.
	- keep Trellis for non-commercial assets.
